# Project Continuity

**Status:** active, early development (0.x).

**If the maintainer becomes unreachable** for 90 days: any contributor may open an issue titled
"Maintainer unreachable". After a further 30 days without response, the project may be forked
and continued under a new name, or ownership requested via GitHub and PyPI's abandoned-project
processes.

## Handoff documents

- [MAINTAINER.md](MAINTAINER.md): who maintains the project and which accounts exist
- [RELEASE.md](RELEASE.md): how to publish a release
- [CONTRIBUTING.md](CONTRIBUTING.md): development setup, tests and contribution process
- [ARCHITECTURE.md](ARCHITECTURE.md): how the code is organised
- [SECURITY.md](SECURITY.md): how to report vulnerabilities

## Access a successor needs

- GitHub repository admin
- PyPI project ownership (publishing itself uses trusted publishing, no secret to hand over)
